# CelestineMD v0.1 requirements

See the project plan. Summary:

- Open plain Markdown vault folders (Obsidian-inspired wikilinks / graph workflow)
- File tree, fuzzy opener (`Mod+O`), command palette (`Mod+P`), graph (`Mod+G`)
- Wikilinks, embeds, outline, backlinks, edit + reading preview
- CSS-variable theme packs + Omarchy `terminal` bridge
- Terminal/ASCII UI with shortcut labels; `?` cheat sheet
- Linux, macOS, Windows via egui/eframe
- No plugins, Canvas, Sync, or full community CSS theme engine
